初等方阵配置

$$ \text{初等方阵：由单位矩阵通过一次初等变换得到的矩阵} $$
$$ P_{ij} = \text{交换单位矩阵的第 } i \text{ 行和第 } j \text{ 行} $$
$$ \text{效果：} P_{ij} \times A \text{ 交换矩阵 } A \text{ 的第 } i \text{ 行和第 } j \text{ 行} $$
$$ D_i(k) = \text{单位矩阵的第 } i \text{ 行乘以 } k \neq 0 $$
$$ \text{效果：} D_i(k) \times A \text{ 将矩阵 } A \text{ 的第 } i \text{ 行乘以 } k $$
$$ T_{ij}(k) = \text{单位矩阵的第 } i \text{ 行加上 } k \text{ 倍第 } j \text{ 行} $$
$$ \text{效果：} T_{ij}(k) \times A \text{ 将矩阵 } A \text{ 的第 } i \text{ 行加上 } k \text{ 倍第 } j \text{ 行} $$
