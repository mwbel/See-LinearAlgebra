# 线性代数可视化模块

## 📐 项目简介

线性代数可视化模块是一个交互式学习平台，旨在通过直观的可视化帮助学习者深入理解线性代数的核心概念。本模块基于上海交通大学《线性代数 第3版》教材开发，涵盖了从行列式到线性变换的完整知识体系。

## ✨ 主要特性

- **18个课程可视化入口**：覆盖线性代数7大章节的核心概念；另有辅助和兼容页面不计入课程入口
- **统一的设计风格**：蓝紫渐变背景 + 白色卡片布局，提供优雅的视觉体验
- **实时交互控制**：通过滑块和输入框动态调整参数，即时查看结果
- **数学公式渲染**：使用MathJax完美展示LaTeX数学公式
- **几何意义解释**：每个概念都配有详细的几何解释和实例演示
- **响应式设计**：适配桌面、平板和移动设备

## 📚 内容结构

### 第一章 行列式
- **二阶行列式**：平行四边形面积的几何意义
- **三阶行列式**：平行六面体体积的可视化
- **n阶行列式**：交互比较行排列、列排列和双排列定义，支持 2–5 阶矩阵
- **行列式性质**：可视化转置、交换、数乘、可加及初等行列变换

### 第二章 矩阵
- **矩阵运算**：加法、乘法、转置的交互演示
- **高斯消元法**：逐步展示矩阵化简过程
- **初等方阵**：初等变换的矩阵表示

### 第三章 n维向量与线性方程组
- **线性方程组**：唯一解、无穷多解、无解的几何解释
- **向量投影**：投影和正交分解的可视化
- **矩阵的秩**：秩的概念及其几何意义

### 第四章 线性空间
- **向量空间**：线性组合、基和维数的展示

### 第五章 矩阵的对角化
- **特征值分解**：特征值和特征向量的几何意义
- **旋转矩阵**：2D和3D旋转变换
- **正交分解**：QR分解的可视化
- **奇异值分解(SVD)**：理解SVD的几何意义 ⭐ 新增
- **最小二乘法**：数据拟合与线性回归 ⭐ 新增

### 第六章 实二次型
- **二次型标准化**：将二次型化为标准形 ⭐ 新增

### 第七章 线性变换
- **线性变换**：矩阵作为线性变换的动态演示

## 🚀 使用方法

### 本地访问

1. 启动本地服务器（推荐使用Python）：
```bash
cd /path/to/See-LinearAlgebra
python3 -m http.server 8000
```

2. 在浏览器中访问：
```
http://localhost:8000/
```

### 页面导航

- **主页**：`index.html` - 模块概览和章节导航
- **各章节页面**：位于 `pages/` 目录下

### 交互操作

1. **调整参数**：使用输入框或滑块修改数值
2. **查看公式**：数学公式自动渲染，支持LaTeX语法
3. **观察可视化**：右侧图表实时更新
4. **切换页面**：通过左侧导航栏快速跳转

## 🔧 技术栈

- **前端框架**：原生HTML5 + CSS3 + JavaScript
- **数学渲染**：MathJax 3.x
- **图形库**：Plotly.js（2D/3D可视化）
- **样式方案**：CSS Grid + Flexbox
- **动画效果**：CSS Transitions

## 📖 学习建议

### 推荐学习顺序

1. **行列式**（几何意义）
   - 从二阶行列式开始，理解面积的概念
   - 进阶到三阶行列式，理解体积

2. **矩阵运算与高斯消元**
   - 掌握基本的矩阵运算
   - 学习高斯消元法求解线性方程组

3. **向量空间**
   - 理解向量的线性组合
   - 掌握基和维数的概念

4. **特征值分解与SVD**
   - 理解特征值和特征向量的几何意义
   - 学习矩阵对角化
   - 深入理解奇异值分解(SVD)

5. **线性变换**
   - 将矩阵理解为线性变换
   - 观察变换对图形的影响

### 使用技巧

- **多次实验**：尝试不同的参数组合，观察变化规律
- **对比学习**：使用预设示例对比不同情况
- **记录笔记**：记录重要的观察和理解
- **结合教材**：配合教材理论学习，加深理解
