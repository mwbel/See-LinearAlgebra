# 线性代数模块 - Google DynamicView 风格

## 🎨 设计特点

### 三栏布局（Google DynamicView 风格）

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部导航栏                                │
├──────────┬────────────────────────────┬─────────────────────┤
│          │                             │                     │
│  左侧栏  │       中间内容区              │      右侧栏         │
│          │                             │                     │
│ 章节导航  │      章节内容               │    学习进度         │
│ 快速链接  │      可视化卡片             │    统计信息         │
│          │                             │    推荐学习         │
│          │                             │    学习提示         │
│          │                             │                     │
└──────────┴────────────────────────────┴─────────────────────┘
```

### 布局规格

- **左侧栏**: 260px
  - 章节导航（锚点跳转）
  - 快速链接（直接跳转到可视化页面）
  - Sticky定位，随页面滚动

- **中间内容区**: 自适应（flex: 1）
  - 欢迎区域
  - 章节内容（按章节分节）
  - 可视化卡片（网格布局）
  - 最小宽度：自适应

- **右侧栏**: 280px
  - 学习进度（进度条动画）
  - 统计信息（数字动画）
  - 推荐学习路径
  - 学习提示
  - Sticky定位，随页面滚动

### 响应式断点

- **桌面**: > 1200px
  - 完整三栏布局

- **平板**: 992px - 1200px
  - 左栏 240px + 中间内容 + 右栏 260px

- **小型平板**: 768px - 992px
  - 中间内容 + 右侧栏
  - 左侧栏移至顶部

- **手机**: < 768px
  - 单栏布局
  - 所有侧边栏可折叠

## ✨ 交互功能

### 1. 章节导航
- 点击左侧章节链接，平滑滚动到对应章节
- 自动高亮当前章节（滚动监听）
- URL更新（支持后退按钮）

### 2. 卡片动画
- 悬停效果：上移 + 放大
- 阴影增强
- 边框高亮（Google蓝色）

### 3. 进度条动画
- 页面加载时从0%动画到目标值
- 渐变色彩（蓝到绿）

### 4. 返回顶部按钮
- 滚动超过300px时显示
- 点击平滑滚动到顶部
- 悬停放大效果

### 5. 统计数字动画
- 从0开始计数到目标值
- 每50ms更新一次

### 6. 滚动位置记忆
- 页面刷新后恢复滚动位置
- 使用sessionStorage存储



```javascript

// 更新当前章节高亮
```

3. **视觉层次**: 清晰的信息架构和视觉引导
4. **交互友好**: 平滑滚动、动画反馈
5. **响应式**: 适配各种屏幕尺寸
6. **性能优化**: CSS动画、虚拟滚动
